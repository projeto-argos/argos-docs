# Registro de atividades — 14/08/2026

## Objetivo

Organizar o ambiente de colaboração, desenvolvimento e documentação do projeto interdisciplinar ARGOS.

## Atividades realizadas

- Criação e configuração da organização `projeto-argos` no GitHub.
- Configuração do perfil público e da identidade visual da organização.
- Criação dos repositórios `.github`, `argos-docs`, `argos-web-crud`, `argos-bd`, `argos-landingpage` e `argos-ai`.
- Criação da equipe `equipe-argos` e configuração das permissões.
- Criação do guia de contribuição e do modelo de Pull Request.
- Proteção da branch `main`.
- Definição da exigência de Pull Request e aprovação de outro integrante.
- Definição do uso de **Squash and merge**.
- Configuração da exclusão automática de branches após o merge.
- Teste do processo de criação, revisão, aprovação e merge de Pull Requests.
- Definição do Jira como ferramenta para acompanhar as demandas.
- Criação, configuração e teste do agente `Guia GitHub do ARGOS`.
- Organização inicial da base de conhecimento do agente.

## Decisões tomadas

- Não realizar alterações diretamente na branch `main`.
- Desenvolver cada atividade em uma branch própria.
- Exigir a revisão de outro integrante antes do merge.
- Utilizar o Jira para demandas, responsáveis, prazos e progresso.
- Utilizar o GitHub para código, documentação e revisão.
- Considerar somente os requisitos do primeiro ano nesta etapa.

## Próximas atividades

- Configurar o projeto e as demandas no Jira.
- Distribuir as responsabilidades entre os integrantes.
- Adicionar os artefatos técnicos e de UX aos repositórios.
- Finalizar a base de conhecimento do agente.
